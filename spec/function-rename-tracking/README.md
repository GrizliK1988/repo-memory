# Function rename tracking

Status: planned post-kickoff feature. This follows the initial
[function-result delivery](../function-results/README.md).

| ID | Task | Dependencies |
| --- | --- | --- |
| FRT001 | [Automatic renamed-function counterparts](001-automatic-counterparts.md) | FR003, K033 |

The first function-result query accepts an explicit counterpart when a function
was renamed. FRT001 adds automatic correspondence only where independent evidence
identifies one unique function. Until then, an unresolved potential rename is not
reported as a confirmed function addition or removal.
