# K041 — Compact source and logic change report

Status: done. Roadmap stage: 2, report extension for the supported subset.

Dependencies: [K013](013-analysis-api.md), [K014](014-branches.md).
Can follow K014 directly; its numeric ID does not require completing K015–K040.

Source: [compact report contract](../../docs/ifds/COMPACT_REPORT.md) and
[SPEC sections 6.4 and 7](../../docs/ifds/SPEC.md#64-grouping-and-required-summary-content).

## Scope

- Introduce a compact structured projection centered on value sources at observations,
  controlling guards, overwrite precedence, and before/after semantic changes.
- Derive human text and agent JSON from the same facts; provide explicit full-evidence
  output and document the command's output-mode migration.
- Preserve direct writers, upstream origins, operand roles, matching uncertainty,
  supported guards, full analysis scope, and unresolved source sets.
- Avoid per-path enumeration and duplicate descriptions of one added/changed source.
  Display shared controls and dependencies once, with evidence references.

Excludes new language support, K032 predicate theories, automatic bug diagnosis,
history mining, and treating a presentation reduction as reduced analysis scope.
This is an additional contract; completed K013 remains the baseline full API.

## Required unit tests

| Test suffix | Required evidence |
| --- | --- |
| `sequential_guards` | The documented example has three sources, two guard identities, a fallback and ordered overwrite rule; independent expected outcomes are 1/2/3 for neither/only flag/flag2. No path-product enumeration in text or compact JSON. |
| `guard_only_change` | Same source definitions before/after, one selection change with guard polarity; no invented source addition/removal. |
| `reordered_priority` | Reordering conditional writes retains sources and guard names but changes which write wins when both apply. |
| `nested_guards` | Shared nested control retains conjunction and else polarity; a bare flag list cannot falsely imply unconditional applicability. |
| `early_return` | New return and changed continuation are explicit; repeated return syntax keeps honest alignment uncertainty if correspondence is unresolved. Source code is not rewritten for the expected result. |
| `operand_and_origins` | Separate direct writer, parameter/upstream input, and computed consumer operand; `x` in `return x + 4` is not the entire result or the literal 4. |
| `overwritten_and_copied` | Reviewed copy-before-overwrite examples retain the old origin in the copy and exclude it from uses of the overwritten x. |
| `equal_rhs_distinct_writes` | Distinct writes of 1 remain distinct sources; inserting `x = x` remains an added writer with retained upstream provenance. |
| `expression_only_change` | A changed operator with the same source bindings is visible; changed source logic is not reduced to source-set equality. |
| `observations_and_grouping` | Distinct affected returns/inputs remain identifiable; equivalent facts are shared; changed source propagating through unchanged consumers is represented without repeating every hop. |
| `uncertainty_and_scope` | Full graphs plus ambiguous alignment do not yield a complete comparison; unknown source sets are not exhaustive; open caller boundaries remain scoped. |
| `guard_versions` | Same guard text with distinct binding/value identities is not merged or simplified unsafely. Unsupported conjunctions remain unknown until their language support exists. |
| `shared_conditions` | Equivalent supported alternatives may share a proved compact rule; simplification cannot turn unresolved reachability into an established relation. |
| `output_contract` | Versioned deterministic serialization, resolvable evidence references, and text/JSON semantic parity; full API/evidence output preserved. |
| `presentation_budget` | Shared guards/sources do not multiply with witnesses; omitted groups are counted and retrievable; analysis and presentation truncation remain distinct. |

All named requirements have corresponding Rust unit tests under `src/ifds/`.

## Verification
